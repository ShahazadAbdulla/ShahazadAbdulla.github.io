**Technology Stack:** Python, Computer Vision, NLP, IoT

Developed **NeuraHome**, an AI-powered home automation system that allows users to control their environment using both **natural language commands** and **hand gestures**.

The system leverages advanced computer vision for gesture recognition and natural language processing (NLP) to interpret user voice commands, providing a seamless and intuitive interface for smart home control.
