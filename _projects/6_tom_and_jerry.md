**Technology Stack:** ROS 2, Python, TurtleSim

Developed a custom **ROS 2 simulation** using the `turtlesim` package where a turtle named **Tom** autonomously chases another turtle named **Jerry**.

This project demonstrates proficiency in:

- **ROS 2 Nodes & Topics:** Managing communication between multiple agents.
- **Frame Transformations (TF2):** Calculating relative positions and velocities.
- **Control Algorithms:** Implementing proportional controllers for smooth pursuit behavior.
