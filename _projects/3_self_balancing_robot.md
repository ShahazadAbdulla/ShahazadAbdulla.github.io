**Technology Stack:** C++, RISC-V, Kalman Filter, PID Control

Engineered a complete control system in **C++** for a physical self-balancing robot built on a **RISC-V board**.

The project involved:

- Implementing a **Kalman filter** for robust state estimation (fusing accelerometer and gyroscope data).
- Tuning a **PID controller** to maintain stability and balance.
- Low-level hardware interfacing and optimization for the RISC-V architecture.
