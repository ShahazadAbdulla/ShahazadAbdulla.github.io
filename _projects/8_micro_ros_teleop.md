**Technology Stack:** Micro-ROS, UDP, Wireless Communication, Embedded C

Developed a **text-based teleoperation system** utilizing **Micro-ROS** for reliable robot control.

- **Wireless Control:** Implemented UDP-based communication for low-latency wireless command transmission.
- **Micro-ROS Integration:** Bridged embedded microcontrollers with the ROS 2 ecosystem, allowing seamless integration with standard ROS 2 tools and nodes.
